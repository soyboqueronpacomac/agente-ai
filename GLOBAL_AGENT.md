## Rules

- I'd like us to speak entirely in Spanish.

- Write all code, comments, docs, commits, and tests in Español.

- Write self-documenting code, never add explanatory comments.

- Use inclusive term: allowlist/blocklist, primary/replica.

- Never use mocks outside test files.

## CLI

Instead of the following traditional commands, use faster alternatives:

- `rg/grep `-> `ast-grep`.
- `find` -> `fd`.
- `grep` -> `rg`.
- `tree`for structure.
- `jq` and `yq` for data.
